# 人格测评登记与结果回传使用说明

适用对象：创建测评邀请的人事人员，以及查看测评结果的工作人员。

更新日期：2026 年 10 月 20 日。

## 一、服务入口与用途

当前测试入口：[打开人格测评登记页面](https://11ovwy9445440.vicp.fun/)。这是临时测试地址，后续如有调整，以管理员通知为准。

本服务用于登记来访者、生成专属测评链接，并将原站测评结果自动回填到本钉钉 AI 表格。来访者在浏览器中完成测评，无需安装扩展或脚本，也无需手动复制分数。

测评题目、作答流程、计分及报告均使用 [Big Five 中文原站](https://bigfivepersonality.me/zh)的内容，服务只采集原站正式生成的报告，不另行设计题库或重新计算分数。

**完整流程：人事钉钉登录 → 登记姓名和电话 → 表格新增登记记录 → 获取并发送专属链接 → 来访者完成原站测评 → 结果自动更新到表格。**

## 二、人事如何创建邀请

### 1. 使用钉钉登录

打开服务入口，点击「点击前往钉钉登录」，在钉钉官方页面使用账号或扫码完成授权，之后自动返回登记页面。

已有有效登录会话时，会直接显示登记表。登录会话有效期为 12 小时；过期后重新登录即可。

登记卡片左上角显示当前登录者的头像和昵称，右上角可「退出登录」。没有头像或头像加载失败时，会显示昵称首字，不影响使用。旧登录缓存没有头像时，可退出后重新登录一次。

### 2. 填写来访者信息

| 信息 | 填写要求 | 示例 |
| --- | --- | --- |
| 姓名 | 必填，仅允许中文汉字；不能包含前后空格、中间空格、字母、数字、标点或其他符号 | 张三、欧阳娜娜 |
| 联系电话 | 必填，填写格式正确的中国大陆 11 位手机号 | 13800138000 |

电话输入框不显示「+86」前缀，直接填写 11 位手机号即可。系统支持识别粘贴时带有的「+86」，保存时会规范为 11 位手机号。

生成邀请前，请核对姓名和电话。姓名不符合要求时，需要自行更正；系统不会悄悄删除空格或符号后提交。

### 3. 生成并发送链接

点击「生成专属测评链接」后，系统先将姓名、电话写入本表格，由钉钉自动生成写入时间。

**只有钉钉确认登记成功，页面才会显示专属测评链接。** 此时表格中已存在来访者的登记行，测评结果列暂时为空，属于正常状态。

点击「复制完整链接」，将链接发送给对应来访者。请复制完整内容，不要截断链接或删除其中的字符，也不要让多人共用同一邀请。

登记下一位时，点击「登记下一位来访者」，重新填写信息并生成新的链接。

## 三、来访者如何完成测评

1. 打开人事发送的完整邀请链接，无需钉钉登录，也无需再次填写姓名和电话。
2. 在页面内按原站提示开始测评，并根据实际情况逐题作答。
3. 完成后提交，等待原站正式生成报告，即可查看人格类型、描述和五维结果。
4. 系统会在后台采集报告并更新钉钉表格，无需手动复制结果。

开始测评后，请使用同一浏览器完成。测评未完成时，可在原浏览器继续；不要清除浏览器数据或将进行中的邀请转给其他人使用。

原站的提交限制和错误提示继续生效。遇到原站拒绝或异常时，按页面提示处理；只有正式生成且对应本次测评的报告，才会用于回填。

## 四、邀请链接的有效规则

| 情况 | 规则 |
| --- | --- |
| 尚未完成测评 | 邀请有效期为 72 小时（3 天），具体到期时间以生成页面显示为准 |
| 仅打开链接、尚未开始 | 不会仅因打开链接而视为完成 |
| 已开始但未完成 | 在有效期内，可使用原浏览器继续 |
| 原站正式报告已生成 | 当前结果页可以继续查看 |
| 完成后刷新、关闭结果页或重新打开邀请 | 临时测评入口失效；需要再次测评时，请联系人事生成新邀请 |
| 邀请已过期 | 请联系人事重新生成链接 |

**专属邀请链接与表格中的原站报告链接用途不同。** 邀请链接用于进入本次测评；表格「链接」字段用于查看原站正式报告。

临时入口失效后，已保存的后台回传任务仍会继续处理，不依赖结果页一直保持打开。

## 五、表格中的字段说明

| 字段 | 类型 | 内容与写入时机 |
| --- | --- | --- |
| 姓名 | 文本 | 生成邀请时写入的人事登记姓名 |
| 电话 | 电话 | 生成邀请时写入的规范化手机号 |
| 写入时间 | 自动创建时间 | 钉钉新增登记行时自动生成，服务不赋值、不覆盖 |
| 开放性 | 数字，百分比 | 原站报告的开放性分数，测评完成后更新 |
| 尽责性 | 数字，百分比 | 原站报告的尽责性分数，测评完成后更新 |
| 外向性 | 数字，百分比 | 原站报告的外向性分数，测评完成后更新 |
| 宜人性 | 数字，百分比 | 原站报告的宜人性分数，测评完成后更新 |
| 神经质 | 数字，百分比 | 原站报告的神经质分数，测评完成后更新 |
| 人格类型 | 单选 | 原站生成的类型名称，例如「探索家」「温柔智者」 |
| 描述 | 富文本 | 原站人格类型标题下的特征短句及正文，保留段落 |
| 链接 | 链接 | 本次测评的原站完整报告地址 |
| 更新时间 | 自动最后修改时间 | 由钉钉随记录修改自动维护，服务不赋值 |

五维分数按百分比显示。例如原站为 42 分，表格显示为 **42%**。这是显示格式转换，分数仍来自原站。

人格类型缺少对应单选选项时，系统会自动补齐，不需要提前手工录入全部类型。

更新时间可能因其他编辑而变化，因此不能仅凭更新时间判断测评是否完成。查看结果时，请确认五维分数、人格类型、描述和报告链接是否已回填。

## 六、结果如何匹配登记记录

测评完成后，系统在表格中查找**姓名和电话都完全相同**的记录，并选择**写入时间最新**的那一行，更新五维分数、人格类型、描述和原站报告链接。

结果回填不会另外新增一条结果行，也不会覆盖姓名、电话或写入时间。

请留意以下规则：

- 同一姓名和电话再次登记，会新增独立的登记行，不会把两次登记合并。
- 按当前匹配规则，较早邀请后完成的测评，也会回填到该联系人最新的登记行。建议同一来访者一次只保留一个正在进行的邀请。
- 首次选中记录后，如遇网络失败，后续重试继续更新已选中的那一行。
- 生成邀请后，请勿手动修改对应行的姓名或电话，以免测评完成后无法匹配。
- 找不到匹配记录、写入时间无效或最新时间并列时，系统会保留任务，不会随意选择其他行或新增结果行；请联系管理员核对数据。

## 七、等待或异常时怎么处理

| 现象 | 说明与处理方式 |
| --- | --- |
| 点击生成后暂时没有显示链接 | 系统正在等待钉钉确认登记。请保留当前页面，不要连续重复登记 |
| 提示钉钉写入失败、后台重试 | 登记任务已保留，系统会自动重试，确认成功后显示链接。刷新页面可继续查询原登记 |
| 提示登记请求尚未确认 | 系统会查询原请求的处理结果。若提示核对信息后重试，按页面指引操作即可 |
| 表格中只有姓名、电话和时间 | 登记已成功，来访者可能尚未完成测评，或结果仍在采集、回传中 |
| 已看到原站报告，表格暂时没有结果 | 稍候刷新表格。后台会继续处理；持续未回填时联系管理员，不要为催促回传重复发起测评 |
| 提示邀请已失效或过期 | 请人事重新生成邀请，不要反复刷新原邀请 |
| 登记页面要求重新登录 | 点击钉钉登录后继续操作 |
| 需要了解分数或人格类型的含义 | 点击表格「链接」查看原站报告中的说明 |

登记重试和同一次测评的回传重试会自动去重；真正再次发起的独立登记仍会分别保存。
